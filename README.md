Context: The project analyzes the sales and marketing performance of an e-commerce company.
The data includes orders, products, advertising spend, and user behavior.
The goal is to identify opportunities to improve conversion, profitability, and retention.
The analysis was conducted using Python, SQL, A/B testing, and visualization in Power BI.

Analysis: The datasets for orders, the product catalog, and marketing campaigns were cleaned and linked.
Metrics such as revenue, profit, average order value, advertising spend, and conversion were analyzed.
Funnel stages, user drop-off, cohorts, and retention were also evaluated.
Finally, an A/B test was analyzed to determine the impact of changes to the purchase process.

Conclusions: The analysis identified the funnel stages with the highest user churn and opportunities for improvement.
The cohorts showed differences in customer retention and repeat business over time.
The A/B test provided statistically significant evidence to determine which version generated better results.
The findings support decisions aimed at optimizing campaigns, products, conversion, and profitability.
